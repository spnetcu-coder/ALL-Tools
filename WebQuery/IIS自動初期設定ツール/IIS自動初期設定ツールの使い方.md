# IIS自動初期設定ツールの使い方

## 概要

`config.json` に記載された情報をもとに、IIS（Default Web Site）へ仮想ディレクトリ（現時点）を自動で登録するツールです。
既に登録済みのエイリアスはスキップされ、未登録のものだけが新規作成されます。

## フォルダ構成

```
IIS自動初期設定ツール/
├── main.exe      … 実行ファイル
└── config.json   … IISに設定する情報（exeと同じ階層に配置）
```

## 使い方

### 1. 登録するディレクトリの設定（必要に応じて）

エイリアスに対応して登録するディレクトリについては、`config.json` ファイルを開き、
以下の`"webquery_path"`(config.jsonファイルのコードを一部抜粋)の参照ディレクトリを手動で編集してください。

```json
{
	"site_name": "Default Web Site",
	"webquery_path": "C:\\Program Files\\SystemConsultant\\WebQuery",
	"virtual_directories": [
		{
			"alias": "/sn",
			"sn_path": "\\cgi-bin"
		}
	]
}
```

- 各エイリアスに対応するパス：（`sn_path` / `async_path` / `wq_path` / `xml_path`）が参照ディレクトリです。
- 実際に登録される物理パスは `webquery_path` ＋ 各エイリアスに対応するパス の値になります。
  - 例：`/sn` → `C:\Program Files\SystemConsultant\WebQuery\cgi-bin`
- JSON内でパスを記載する際は、`\` を `\\` と記述してください。

### 2. exeの実行

`IIS自動初期設定ツール` フォルダに格納されている `main.exe` をダブルクリックで実行してください。

実行すると、コンソールに以下のような結果が表示されます。

#### 仮想ディレクトリごとの結果

- **登録済みの場合**
  - 表示例：`設定済みです：sn`
  - 既にIISに登録されているため、そのエイリアスはスキップされます。

- **新規登録の場合**
  - 表示例：`未設定：sn` → `snディレクトリの作成に成功しました。`
  - IISに仮想ディレクトリを新規に登録します。

#### ツール終了時の表示

- `登録する情報はありませんでした。` → `Enterキーで終了`
  - 新規登録する仮想ディレクトリが無い場合に表示されます。
  - Enterキーを押すとツールが終了します。

- `【登録完了：Enterキーで終了】`
  - 1件以上の仮想ディレクトリを登録した場合に表示されます。
  - Enterキーを押すとツールが終了します。

## 注意点

- **exeと同階層にある `config.json` ファイルは削除しないでください。**
  削除すると、exeがIISに設定する情報を読み込めなくなります。
